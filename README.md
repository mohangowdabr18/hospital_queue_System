# hospital_queue_System

Smart OPD Patient Flow & Department Queue Management System.

## Features
- **User / Admin Role Separation**: Dedicated Patient Portal and secure Admin Dashboard (PIN-protected).
- **Patient Registration & Triage**: Automatic queue token assignment, priority/emergency routing.
- **Multi-Department Support**: General Medicine, Pediatrics, Cardiology, Orthopedics, ENT, Dermatology, Emergency.
- **Real-Time Display**: Live waiting queue, now serving board, doctor consult status, and audio announcements.
- **Analytics & Counter Controls**: Wait-time estimation, patient call/skip/complete actions.
